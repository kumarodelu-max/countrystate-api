React Country State Dropdown API

Building a signup form in React or Next.js? Use our zero-latency REST API to instantly populate cascading dropdowns for countries, states, and cities.

React Fetch Example

useEffect(() => {
  fetch('https://countrystatecityapp.in/api/v1/countries', {
    headers: { 'Authorization': 'Bearer YOUR_KEY' }
  })
  .then(res => res.json())
  .then(json => setCountries(json.data));
}, []);
