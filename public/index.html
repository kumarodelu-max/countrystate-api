API Documentation

Step-by-step guide to integrate the CountryState API

1. Authentication

Every API request requires an active API Key passed in the Headers.

Request Header 
Authorization: Bearer YOUR_API_KEY

2. Get All Countries

Fetch a list of all supported countries, their ISO codes, and metadata.

GET /api/v1/countries 
curl -X GET "http://localhost:3000/api/v1/countries" \
  -H "Authorization: Bearer YOUR_API_KEY"

Sample Response:

{
  "status": "success",
  "data": [
    {
      "id": 1,
      "name": "India",
      "iso2": "IN",
      "currency_code": "INR",
      "emoji": "🇮🇳"
    }
  ]
}

3. Get States by Country

Fetch all states for a specific country using its 2-letter ISO code.

GET /api/v1/countries/:iso2/states 
curl -X GET "http://localhost:3000/api/v1/countries/IN/states" \
  -H "Authorization: Bearer YOUR_API_KEY"

4. Get Cities by State

Fetch all cities within a specific state.

GET /api/v1/countries/:iso2/states/:stateCode/cities 
curl -X GET "http://localhost:3000/api/v1/countries/IN/states/MH/cities" \
  -H "Authorization: Bearer YOUR_API_KEY"
